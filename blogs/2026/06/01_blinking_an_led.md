# 01 - blinking an LED

welcome back to my Arduino series, where i will be going through my Uno kit in a feeble attempt to learn more about this field.

## 01 - introduction
lets get started by trying to blink some lights. we need the following items:

1. 1 x the Uno board
2. 1 x bread board
3. 1 x LED (i chose Green)
4. 1 x 220 ohm resistor

### 01.a hardware
![[00a-blinking-led.png|248]] 
copyright issues related to copying this image aside, this is a visual of the flow of current through our system. a pin (say 8) passed the current to a resistor that converts it down to a state where an LED can function without going kaboom, then the LED does its magic by connecting to ground (GND) and completing the loop.
